Academic Architecture Note

Why a Hybrid Architecture (Rule-Based + RAG)?

In life-or-death disaster situations, relying purely on generative LLMs creates unacceptable risks: hallucinated helplines, dangerous evacuation advice, and high network latency. DisasterShield solves this through a dual-mode hybrid architecture:

Mode A: Rule-Based Emergency Trees 100% deterministic decision logic for active crises. Works offline, guarantees zero hallucinations, and guides the user through critical life-safety branches.
Mode B: RAG Document Assistant Answers broader preparedness questions grounded strictly in official PDF guidelines with exact page citations and hybrid FAISS retrieval.
Zero Hallucinated Hotlines Both modes exclusively reference verified emergency hotlines: 112 (ERSS), 1078 (NDRF), 101 (Fire), and 108 (Ambulance).
Local & Secure Runs 100% locally with zero required paid API keys, protected against prompt injection and arbitrary file execution.
